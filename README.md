# 💫 About Me

Hi, my name is Jacob Moracha. I'm a software and data engineer based in Nairobi, Kenya.

I work in two directions: building web and mobile applications with React, React Native, Node.js and Python, and working with data — pipelines, analytics and the occasional forecasting model. I like problems where the two meet, and I like making complicated things feel simple, whether that's in code, in writing, or on a stage at a developer meetup.

I'm always learning something new, and I try to share it as I go.

- 🚀 I'm currently working across software engineering and data engineering
- 🌱 Lately curious about API management, AI governance, MCP, and where agents meet real-world data
- 🤝 I'm open to collaborating on interesting open-source projects
- ✉️ You can reach me at **jacobmoracha@gmail.com**
